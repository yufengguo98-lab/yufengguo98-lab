## AnyaOS

常驻桌面的 3D 形象，能语音对话、记住你们聊过的事，还能通过插件和 MCP 操作你电脑上的其他软件。比如一句话让她去 arXiv 搜论文、读全文、存进 Zotero、写成 Obsidian 笔记。

- **长期记忆**：数据存在本地
- **插件与 MCP**：Zotero、Obsidian、arXiv、Excel、Word……
- **语音对话**与 **3D 桌面伙伴**
- **自带 API Key**：支持 DeepSeek、通义千问、OpenAI、Ollama 等
